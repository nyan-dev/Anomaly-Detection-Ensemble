# Dataset Notes

## Source

**CMS DE-SynPUF 2010 Outpatient Claims**
- Download: [Kaggle — CMS DE-SynPUF 2010 Outpatient Claims](https://www.kaggle.com/datasets/kukulauren/cms-desynpuf-2010-outpatient-claims)
- Original source: [CMS (Centers for Medicare & Medicaid Services)](https://www.cms.gov/Research-Statistics-Data-and-Systems/Downloadable-Public-Use-Files/SynPUFs)

## Data Type

This dataset is **fully synthetic** — generated by CMS to simulate real Medicare claims patterns without exposing any real patient data. No privacy concerns or usage restrictions for research.

## Setup

Notebook 01 (`01_data_setup_and_kaggle_download.ipynb`) automates the download using the Kaggle API.

```bash
# Place kaggle.json in ~/.kaggle/ then run Notebook 01
# It will download and extract the dataset automatically
```

> The dataset CSV is not included in this repository due to file size. Use Notebook 01 to download it.

## Size

| Stage | Records |
|---|---|
| Raw download | ~2.3 million rows |
| After cleaning (outpatient only) | ~175,000 claims |
| Train split (80%) | ~140,000 claims |
| Test split (20%, 3% anomaly injection) | ~35,000 claims |

## Engineered Features (14 total)

| # | Feature | Category | Description |
|---|---|---|---|
| 1 | `log_payment` | Monetary | Log-transformed total claim payment |
| 2 | `reimbursement_ratio` | Monetary | Medicare reimbursement / total payment |
| 3 | `deductible_amount` | Monetary | Beneficiary deductible paid |
| 4 | `claim_duration_days` | Temporal | Days between claim start and end date |
| 5 | `admission_month` | Temporal | Month of service |
| 6 | `day_of_week` | Temporal | Day of week of claim submission |
| 7 | `procedure_code_count` | Utilization | Number of distinct procedure codes |
| 8 | `diagnosis_code_count` | Utilization | Number of distinct diagnosis codes |
| 9 | `claim_frequency` | Utilization | Claims per beneficiary in dataset |
| 10 | `provider_anomaly_rate` | Provider-level | Fraction of provider's claims flagged |
| 11 | `claims_per_provider` | Provider-level | Total claims volume per provider |
| 12 | `avg_payment_per_provider` | Provider-level | Mean payment across provider's claims |
| 13 | `inpatient_flag` | Structural | Binary: inpatient vs outpatient |
| 14 | `primary_diagnosis_group` | Structural | Encoded primary ICD diagnosis category |
